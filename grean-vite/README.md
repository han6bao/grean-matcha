# GREAN

Specialty matcha & hojicha café site, Seattle. Plain HTML/CSS built with Vite.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

Outputs static files to `dist/`.

## Deploy on Vercel

Import this repo in Vercel. It auto-detects the Vite framework preset:
- Build command: `vite build`
- Output directory: `dist`

No environment variables are needed.
